KPM — Project Manager

Claude Code 개발 프로젝트 통합 관리 대시보드
Node.js + Express React 18 + Vite Electron 로컬 웹 대시보드
버전: 1.0.0 백엔드: localhost:3001 실행파일: KPM_v1.0.0_portable.exe

개요

Claude Code로 진행하는 여러 게임 개발 프로젝트를 한눈에 관리하기 위한 로컬 웹 대시보드. Electron으로 패키징되어 독립 실행형 앱으로도 사용 가능.

기술 스택

구분기술비고
백엔드Node.js + Express 4포트 3001
프론트엔드React 18 + Vite 5개발 시 포트 5173
데이터 저장JSON 파일projects.json, settings.json
테스트Jest + Supertest / Vitest백엔드 15개, 프론트 10개
패키징Electron + electron-builderportable exe, 1280×900 고정

실행 방법

# 방법 1: Electron 앱
KPM.bat  (또는 KPM_v1.0.0_portable.exe 직접 실행)

# 방법 2: 개발 모드
cd backend && node server.js
cd frontend && npm run dev  →  http://localhost:5173

구현 기능

1. 프로젝트 카드

각 프로젝트를 카드로 표시. 카드에 포함된 정보:

  • 프로젝트 이름 + 상태 선택 (진행중 / 일시정지 / 완료)
  • 지시사항 총 건수 + 마지막 지시 시각
  • 지시사항 목록 (체크박스 완료 처리, ✕ 삭제)
  • 지시사항 입력 필드 (Enter 또는 + 버튼)
  • Plan 파일 진행률 바 (docs/superpowers/plans/*.md의 - [x] 기반)
  • Claude 기록 토글 (최신순 30건)
  • 버튼: ▶ 실행 / Push / 열기 / 기획서 / 문서 / 런처 / 삭제

2. 헤더 버튼

버튼기능
⚙ 규칙공용 규칙 설정 모달 열기
스캔Claude Code 기록에서 프로젝트 자동 탐지
정렬 드롭다운기본 / 이름↑ / 이름↓ / 상태순 / 최근 지시순
새로고침전체 프로젝트 데이터 새로고침
+ 추가프로젝트 수동 등록 모달

3. Claude Code 기록 자동 스캔

~/.claude/projects/ 디렉토리를 탐색해 세션 JSONL 파일의 cwd 필드에서 실제 프로젝트 경로를 추출. 이미 등록된 프로젝트는 제외 후 선택하여 일괄 추가.

4. 최근 실행파일 실행 (▶ 실행)

프로젝트 폴더를 재귀 탐색해 가장 최근 수정된 .exe 파일을 찾아 Windows start 명령으로 실행. node_modules, .git, Library, Temp, obj 등 제외.

5. 런처 배치파일 생성 (런처 버튼)

클릭 시 해당 프로젝트 폴더에 {프로젝트명}.bat 생성. 이 배치파일은 폴더 내 가장 최근 *_portable.exe를 PowerShell로 자동 검색해 실행. 버전이 올라가도 .bat 파일 그대로 사용 가능.

6. 기획서 / 문서 열람

  • 기획서: docs/superpowers/plans/에서 가장 최근 .md 파일을 모달 표시
  • 문서: 프로젝트 전체 탐색, plans 제외 가장 최근 .md 파일 모달 표시
  • 파일 없을 시 버튼에 "없음" 인라인 표시 (alert 팝업 없음)

7. Electron 독립 실행 앱

  • 별도 창으로 실행 (브라우저 탭 아님), 1280×900 고정 해상도
  • Express 백엔드를 내부에서 자동 구동 후 로딩
  • 데이터 파일(projects.json, settings.json)은 exe 위치에 저장 (이식 가능)
  • KPM.bat: 루트에서 가장 최신 KPM_v*_portable.exe를 자동으로 찾아 실행하는 런처

8. 기타

  • Git Push: 카드 Push 버튼 → 해당 프로젝트에서 git push 실행, 인라인 결과 표시
  • VSCode 열기: 열기 버튼 → code {경로} 실행
  • 공용 규칙: 모든 프로젝트에 공통 적용할 규칙 텍스트 목록 관리 (settings.json)
  • 오류 배너: API 실패 시 상단 빨간 배너 표시
