6_IL — 게임 설계서
판타지 중세 설원 서바이벌 디펜스
작성일: 2026-04-21 | 엔진: Phaser 3 + TypeScript | 상태: 브레인스토밍 완료
장르: 뱀서바이벌류 / 타워 디펜스 / 핵앤슬래시 / 영속 마을 / 영구 사망

================================================================================

§1. 비전과 핵심 기둥
================================================================================

[1.1 한 줄 비전]
눈보라 치는 판타지 설원, 낮에는 사냥꾼·밤에는 마을 방어자.
영속으로 쌓이는 마을과 잃으면 돌아오지 않는 동료들 사이에서,
얼마나 오래 버틸 수 있는가.

[1.2 장르 슬로건]
"뱀서류 + 낮/밤 서바이벌 + 타워디펜스 + 핵앤슬래시, 판타지 중세 설원판."

[1.3 4가지 게임플레이 기둥]

☀ 낮의 사냥꾼
  제한 시간 내 설원 탐험. 동료 영입, 자원 수집, 거대동물 사냥.
  시야/안개가 긴장감을 만들고, 대담함과 귀환 타이밍을 저울질.

🌙 밤의 성주
  모닥불로 불빛을 밝히고, 그리드에 바리게이트를 깔고,
  영입한 동료들과 함께 좀비 무리를 새벽까지 막아냄.
  뱀서류 자동 공격 + 타워디펜스 전략 배치.

🏘 영속 마을, 사라지는 동료
  마을은 계속 성장 (영속). 하지만 동료는 영구 사망.
  한 번 죽으면 돌아오지 않음 → "누구를 밖에 데리고 갈지"에 무게감.

🌨 초대형 눈보라
  아주 드문 이벤트. 좀비 + 극한 추위가 동시.
  모닥불/집 밖은 지속 대미지. 모든 시스템이 교차하는 절정.

[1.4 타깃 플레이어 여정]
  - Day 1~5: 생존 학습
  - Day 10~30: 마을 안정화, 동료 누적
  - Day 50+: 장비 빌드 실험, 최고 기록 경신
  - 한 마을당 10~30시간 / 종료 조건: 전멸만 (무한 서바이벌)
  - 전멸 시 점수 기록 + 일부 메타 해금 → 새 마을 시작

[1.5 타깃 플랫폼]
  1차: 웹 브라우저     (Phaser 3 HTML5)
  2차: Steam 데스크톱  (Tauri 래핑)
  3차: iOS / Android   (Capacitor 래핑)

§2. 기술 스택과 아키텍처
================================================================================

[2.1 스택]
  계층              선택                          역할
  ────────────────────────────────────────────────────────
  런타임            브라우저 (Chromium)           1차 타깃
  게임 엔진         Phaser 3                      2D 렌더, 신 관리, 입력
  언어              TypeScript (strict)            타입 안전, 리팩토링 안정성
  빌드              Vite                          HMR, 빠른 개발 루프
  데스크톱 래퍼     Tauri                         Steam 빌드용 실행파일 (~5MB)
  ECS               자체 경량 ECS (bitecs 후보)   수천 엔티티 성능
  맵 에디터         Tiled                         타일맵·콜리전·스폰 포인트
  저장              localStorage (웹) / 파일 (Tauri)  마을 영속 데이터
  오디오            Howler.js                     BGM/SFX 믹싱, 공간 오디오

[2.2 프로젝트 구조]
  6_IL/
  ├── src/
  │   ├── scenes/        # Boot, Preload, Village, Snowfield, UI, ...
  │   ├── ecs/
  │   │   ├── components/  # Position, Velocity, Health, Warmth, AiIntent, ...
  │   │   └── systems/     # MovementSystem, CombatSystem, VisionSystem, ...
  │   ├── gameplay/
  │   │   ├── combat/      # 무기, 룬, 투사체, 대미지 계산
  │   │   ├── village/     # 건물, 자원, 건설 로직
  │   │   ├── barricade/   # 그리드 배치, 충돌, 파괴
  │   │   ├── vision/      # 시야 마스크, 안개
  │   │   ├── cycle/       # 낮/밤 타이머, 이벤트 스케줄러
  │   │   ├── companions/  # 영입, 사망, AI
  │   │   └── blizzard/    # 눈보라 상태 머신
  │   ├── content/         # 데이터 정의 (적, 무기, 건물, 동료 종류)
  │   └── persistence/     # 세이브/로드, 마이그레이션
  ├── assets/
  │   ├── sprites/
  │   ├── audio/
  │   └── maps/            # Tiled .json
  └── src-tauri/           # Tauri 설정 (2차 작업)

[2.3 설계 원칙]
  - ECS로 전투 물량 처리: 좀비 수백 마리 대비.
    Phaser GameObject는 UI/건물 등 소수에만 사용.
  - 데이터 중심(Data-Driven): 적, 무기, 건물, 동료, 룬 모두
    src/content/의 JSON/TS 파일로 선언.
  - 신 경계로 모드 분리: SnowfieldScene(낮)과 VillageScene(밤) 완전 분리.
  - 퍼포먼스 타겟: 좀비 500~800마리 동시, 60 FPS on 중급 데스크톱 브라우저.

§3. 게임 루프 상세
================================================================================

[3.1 하루 사이클]
  단계           길이     주요 행동
  ──────────────────────────────────────────────────────────────────
  낮             8~10분   설원 탐험·영입·사냥·자원 수집. 귀환 타이밍 선택.
  저녁 전환      30초     종탑 종소리. 모든 NPC/동료 자동 귀환. 건물/바리게이트 재배치.
  밤             5~7분    좀비 웨이브 방어. 새벽까지 생존.
  새벽 전환      30초     좀비 잔당 소멸, 시체 자원 회수, 다음 날 준비.

  하루 총 길이: 약 14~18분 / 1~2시간 세션 = 5~8일 진행 가능.

[3.2 낮 — 설원 (Snowfield)]

  구역화:
    구역          내용
    ──────────────────────────────────────────────────────────────
    근교 (반경 1) 사슴·토끼 등 약한 수동 동물 + 드문 자원. 초반 안전 구역.
    중경 (반경 2) 늑대 무리, 더 많은 자원, 룬 조각. Day 4~6부터 등장.
    심경 (반경 3+) 서리 정령·트롤, 철 광맥, 거대동물(보스급), 희귀 룬. Day 8+ 도전 구역.

  귀환 타임아웃: 종 울림 후 설원에 남아있으면 밤을 밖에서 맞음
    → 안전 지대 없음 → 사망 위기.

[3.3 밤 — 마을 방어 (Village Defense)]
  - 웨이브 3~5파동, 점점 강해짐 / 웨이브 간 10~20초 휴식
  - 플레이어: 수동 조작 + 뱀서류식 자동 공격 (장비/룬 기반)
  - 동료: AI, 배치 지점 방어 또는 플레이어 추종
  - 모닥불: 반경 내 화염 DPS + 시야 + 동료 공격력 버프 (+10~20%)
  - 보스 밤: Day 5·10·15·...마다 고정 보스 등장

  보스 종류 (초기 3~5개):
    보스명             특성
    ──────────────────────────────────────────────────────────────
    거대 서리 좀비     높은 체력·물리 공격
    언데드 겨울기사    근접 + 방패, 동료 타겟 유도
    얼어붙은 거인      광역 얼음 브레스, 건물 파괴 특화
    서리 리치          원거리 스킬, 좀비 소환, 창고/밭 노림

[3.4 초대형 눈보라 밤]
  - 주기: 7~15일 랜덤 (시드 기반, 예측 힌트 있음)
  - 경고: 저녁 전환 시 종탑 종소리 + 하늘 어두워짐 + 까마귀 + 30초 카운트
  - 효과: 좀비 수 2배 + 체온 시스템 활성화 + 시야 50% 감소 + 바리게이트 내구도 감소
  - 보상: 생존 시 마을 번영도 보너스 + 희귀 재료 + 메타 해금 포인트 대량

§4. 전투 & 장비 시스템
================================================================================

[4.1 하이브리드 구조]
  층               영속성           획득
  ──────────────────────────────────────────────────────────────────
  기본 장비        영속 (마을 창고)  대장간 제작, 사냥 드랍, 보스 드랍
  (무기·방어구·부적)
  런타임 룬/축복   해당 밤에만       낮 설원 룬 조각 수집, 밤 레벨업 시 선택
  진화 무기        밤 내 일시        기본 무기 + 특정 룬 조합 충족 시 자동 진화

[4.2 무기 카테고리 (6종)]
  무기       공격 패턴         특징
  ──────────────────────────────────────────────────────────────────
  롱소드     전방 휘두르기     균형, 초보 친화
  창         전방 길게 찌르기  긴 사정거리, 관통
  활         자동 조준 원거리  사거리 최장, 근거리 약함
  서리 지팡이 광역 냉기 장판  슬로우 + 광역
  워해머     강한 근접 슬램    기절, 저공속
  쌍단검     고공속 근접       치명타 의존

[4.3 룬 카테고리]
  종류     예시
  ──────────────────────────────────────────────────────────────────
  공격 증강 투사체 +1, 대미지 +20%, 사거리 +15%
  방어      최대 HP +10%, 받는 피해 -10%, 블록 확률
  유틸      이동 속도 +10%, 경험치 +20%, 픽업 반경 +30%
  광역      주변 적에 전기, 화염 장판, 얼음 폭발

[4.4 진화 무기]
  - 기본 무기 + 특정 룬 2~3개 조합 + 레벨 최대치 → 밤 중 자동 진화
  - 진화 시 화려한 이펙트, 공격 패턴 변경 + 대미지 급증
  - 예: 롱소드 + "연속 베기 룬" + "화염 룬" = 염화 폭풍검
  - 진화 효과는 해당 밤 종료 시 사라짐 (기본 무기만 영속)

[4.5 대미지 계산]
  최종 대미지 = 기본 공격력
    × (1 + 룬 공격 증강 합)
    × (1 + 진화 보너스)
    × 크리티컬 배율
    × 약점/저항 배율
    - 적 방어력 (감산)

  타입          농사 효율  전투 가능 무기              전투력  스폰 빈도
  ──────────────────────────────────────────────────────────────────────────
  아저씨(장년 남)  100%    검·창·활·도끼 전부          ★★★★    25%
  아줌마(장년 여)  110%    활·창·단검                  ★★★     20%
  청년 (남/여)      90%    전부                         ★★★★★  10%
  노인 (남/여)      70%    지팡이·활 (제한)             ★★      25%
  아이 (소년/소녀)  60%    활·투석만 (근접 불가)        ★☆      20%

  핵심 감성: 아이 동료는 약하지만 감정적 애착 (영구 사망 무게감↑).
  마을이 "진짜 사는 공간" 느낌.

[6.2 영입 흐름]
  1. 설원에서 NPC 조우 (근교·중경·심경 랜덤 스폰)
  2. 접근 시 F키 → 간단 대화 UI → [영입] / [거절]
  3. 영입 조건: 숙소 여유 슬롯 + 식량 재고 +1일분
  4. 즉시 파티 합류, 저녁 전환 시 자동 귀가

[6.3 전투 스탠스]
  스탠스   행동
  ──────────────────────────────────────────────────────────────────
  따르기   플레이어 반경 ~6타일 유지, 플레이어 타겟 우선
  사수     지정 지점 반경 ~5타일 방어. 범위 밖 무시
  공세     가장 가까운 적 추적·교전, 마을 외곽까지 나감

[6.4 영구 사망 & 부상]
  - HP 0 → 즉시 사망 → 완전 영구 삭제 (기록만 남음)
  - 장비는 시체 회수 시 환수
  - HP 30% 이하: 비명 + 화면 외곽 빨간 깜빡임
  - 사망 시 전체 동료 사기 -10

[6.5 사기 시스템]
  사기     효과
  ──────────────────────────────────────────────────────────────────
  80+      전투력 +10%
  60~80    정상
  30~60    전투력 -10%
  30 미만  매일 5% 확률 탈주

[6.6 명예의 전당]
  사망 동료: 마을 "기억의 돌"에 이름·타입·생존 일수·킬 수·사인 영구 기록.

§8. 아트 & 오디오
================================================================================

[8.1 아트 디렉션]
  픽셀 아트, 중세 판타지 설원.
  캐릭터 16×24 또는 24×32 픽셀 / 타일 32×32.
  팔레트: 32~48 색 제한, 차가운 청록·회백색 + 모닥불/피 오렌지·빨강 대비.
  레퍼런스: Starbound, Kingdom: Two Crowns, Graveyard Keeper, Darkwood

[8.2 시그니처 사운드]
  - "종소리 3타 → 하늘 어두워짐" = 초대형 눈보라 신호
  - 바리게이트 파괴 크릉크릉 소리로 방어선 상태 청각 파악

[8.3 메타 점수 계산]
  Final Score = Days Survived × 10
              + Companions Recruited × 5
              + Bosses Killed × 50
              + Mega Blizzards Survived × 100
              + Resources Accumulated Peak × 0.1
              - Companions Lost × 3

§9. 개발 마일스톤
================================================================================

[9.1 개발 단계]

  Phase 0 — 프로젝트 기반 (1~2주)
    - Vite + Phaser + TypeScript 보일러플레이트
    - ECS 라이브러리 도입, 핵심 타입·이벤트 버스
    - Tiled 맵 로딩 파이프라인, CI

  Phase 1 — 수직 슬라이스 (4~6주)
    - 플레이어 이동 + 근접 무기 1종 + 자동 공격
    - 설원 근교 + 벌목·채광·사냥
    - 마을: 모닥불 + 바리게이트(나무)
    - 낮→밤 전환 + 좀비 웨이브 1종 + 시야 마스크

  Phase 2 — 핵심 시스템 확장 (6~8주)
    - 동료 영입 + 스탠스 3종 + 영구 사망
    - 건물 7종 + L1→L3 업그레이드
    - 밭 + 식량 + 사기 / 룬 시스템 + 진화 무기 2~3종

  Phase 3 — 콘텐츠 폭 (8~10주)
    - 보스 3~5종 + 초대형 눈보라
    - 튜토리얼 + 메타 해금 트리
    - 오디오 풀세트 + 픽셀 아트 최종

  Phase 4 — 폴리시 & 출시 (6~8주)
    - UI 정제, 밸런스 패스
    - Tauri 데스크톱 빌드 + Steam 통합
    - itch.io 웹 데모 → Steam 정식 출시

  총 예상: 약 6~9개월 풀타임 (파트타임 9~12개월)

[9.2 주요 리스크]
  리스크                영향    완화 전략
  ──────────────────────────────────────────────────────────────────────────
  성능 (좀비 500+)      치명적  Phase 1부터 1000마리 스트레스 테스트. ECS, 풀링, flow field.
  솔로 개발 번아웃      높음    2주 단위 마일스톤. itch.io 데모로 조기 피드백.
  스코프 크립           높음    모든 신기능은 Phase 1/2 끝난 후 추가 결정.
  아트 파이프라인 병목  중간    에셋 팩 선활용 → 고유 아트 후반 교체.
  밸런스               중간    Phase 3 끝부터 클로즈드 테스트 (친구 5~10명).
