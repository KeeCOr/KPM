# KPM 프로젝트 대시보드 설계

## 개요

Claude Code로 진행 중인 모든 프로젝트의 지시사항과 진행 상태를 한눈에 볼 수 있는 로컬 웹 대시보드. 프로젝트별 지시를 등록하고 시행률을 확인하며, VSCode를 바로 열 수 있다.

## 기술 스택

- **프론트엔드**: React (Vite)
- **백엔드**: Node.js + Express
- **데이터 저장**: `projects.json` (로컬 파일)
- **실행 방식**: 로컬 서버 (`localhost:3000`)

## 기능

### 대시보드
- 등록된 모든 프로젝트를 카드 그리드로 표시
- 상단에 새로고침 버튼, 프로젝트 추가(+) 버튼

### 프로젝트 카드
각 카드에 표시되는 정보:
- 프로젝트명 + 상태 태그 (진행중 / 일시정지 / 완료) — 사용자가 수동으로 설정
- 총 지시사항 건수 + 마지막 지시 시간
- 지시사항 체크리스트 (체크박스로 완료 표시)
- 진행률 바 (완료 건수 / 전체 건수)
- VSCode 열기 버튼

### 프로젝트 등록
- + 버튼 클릭 → 프로젝트명 + 폴더 경로 입력 모달
- `projects.json`에 저장

### 지시사항 관리
- 카드에서 직접 지시사항 추가/삭제
- 추가 시 타임스탬프 자동 기록

### 진행률 자동 파싱
- 각 프로젝트의 `docs/superpowers/plans/*.md` 파일 스캔
- `- [x]` 완료, `- [ ]` 미완료로 카운트
- 진행률 = plan 파일의 `[x]` 수 / 전체 체크박스 수 (자동)
- plan 파일이 없는 프로젝트는 진행률 표시 없음 (`-`)
- 지시사항 체크박스는 별도로 사용자가 수동 체크 (진행률 계산과 무관)

### 새로고침
- 수동 새로고침 버튼으로 진행률 재계산 (자동 폴링 없음)

### VSCode 열기
- 열기 버튼 클릭 → 서버가 `code <프로젝트 경로>` 실행

## 데이터 구조

```json
{
  "projects": [
    {
      "id": "squad-vs-monster",
      "name": "SquadVsMonster",
      "path": "C:/Users/.../SquadVsMonster",
      "status": "active",
      "instructions": [
        {
          "id": "1",
          "text": "보스 패턴 3종 추가",
          "done": false,
          "createdAt": "2026-04-27T14:30:00Z"
        }
      ]
    }
  ]
}
```

## API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/projects` | 전체 프로젝트 목록 + 진행률 |
| POST | `/api/projects` | 프로젝트 추가 |
| PUT | `/api/projects/:id` | 프로젝트 수정 (상태, 지시사항) |
| DELETE | `/api/projects/:id` | 프로젝트 삭제 |
| POST | `/api/projects/:id/open` | VSCode로 열기 |
| POST | `/api/projects/:id/refresh` | 진행률 재계산 |
