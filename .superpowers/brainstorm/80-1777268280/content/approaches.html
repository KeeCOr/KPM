구현 방법 3가지

하나를 선택해주세요

A

⭐ Node.js + React (추천)

백엔드: Express API 서버 — 프로젝트 폴더 감시, 파일 파싱, VSCode 실행

프론트엔드: React 대시보드 — 실시간 업데이트, 반응형 UI

진행률 자동화: 각 프로젝트의 docs/superpowers/plans/*.md 파일에서 [ ] / [x] 체크박스 파싱

장점

  • pioneer-electron 경험 활용 가능
  • 실시간 파일 감시로 자동 업데이트
  • 확장하기 쉬움

단점

  • Node + React 두 가지 설정 필요
B

Python FastAPI + 간단한 HTML

백엔드: FastAPI — REST API, 파일 파싱, 프로세스 실행

프론트엔드: 순수 HTML/CSS/JS — 프레임워크 없음

진행률 자동화: 동일하게 plan 파일 체크박스 파싱

장점

  • 설정 가장 단순
  • Python으로 파일 처리 강력

단점

  • UI가 덜 동적임
  • Python 환경 필요
C

Next.js 풀스택

백엔드+프론트엔드: Next.js 단일 프로젝트 — API Routes + React

진행률 자동화: 동일하게 plan 파일 체크박스 파싱

장점

  • 하나의 프로젝트로 관리
  • 배포 옵션 다양

단점

  • Next.js 설정 복잡도 있음
  • 로컬 전용 앱에 오버스펙일 수 있음
